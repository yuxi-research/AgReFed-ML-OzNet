# AgReFed-ML-OzNet

This repository accompanies the manuscript:  

**Zhang, Y., Wimalathunge, N., Haan, S., Wang, J., Zou, X., & Bishop, T.** (2025). *High spatio-temporal resolution soil moisture nowcasting at multiple depths with data-driven approaches.* Agricultural Water Management, 312, 109457. https://doi.org/https://doi.org/10.1016/j.agwat.2025.109457  

## Overview

This repository is a modified version of the original [**[Sydney-Informatics-Hub/AgReFed-ML]**](https://github.com/Sydney-Informatics-Hub/AgReFed-ML.git) repository (accessed on 2023-03-27). On top of the original implementation, we introduced several enhancements and customizations to support high-resolution soil moisture nowcasting at multiple depths.  

### Modifications and Additions

- `python_scripts/`: Includes modified Python files  
- `model_Adelong/`: Pretrained models and configuration files for the specific OzNet site used in the manuscript as an example  
- `README.md`: Project description and usage information  

### Original Repository Content

- `Documentation_AgReFed-ML.md`: Original `README.md` file from the source repository, including instructions for installation and usage  
- `docs/`: Original documentation files 
- `notebooks/`: Original upyter notebooks for exploratory data analysis and visualization  
- `python_scripts/`: Core scripts for data preprocessing, model training, and evaluation. Includes original and modified Python files
